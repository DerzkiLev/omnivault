1. Экспорт обновленного HTML для GitHub Pages

Генерирует и скачивает готовый файл index.html, в который ваша текущая библиотека встроена напрямую в переменную DEFAULT_LIBRARY. Просто загрузите этот index.html в репозиторий GitHub Pages, и все изменения сразу откроются на любом устройстве по вашей ссылке!

2. Экспорт и Импорт резервной копии JSON

Сохраните базу в файл .json или загрузите ранее сохраненную копию.

3. Автозагрузка из облачного JSON / GitHub Gist

Вставьте прямую ссылку на raw JSON файл для синхронизации.
